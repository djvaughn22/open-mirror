# Production QA Punch List

Running list of small, concrete UX issues noticed from actual phone/desktop use across the
Open Mirror family — not a place for broad "make it prettier" requests. Add items as you spot
them; when you've got 10-30, hand the whole list to Claude for one targeted cleanup pass.

## How to add an item

One line each. Include: site, page/area, device (if relevant), and what's wrong.

```
- [ ] [site] page/area (device) — what's off
```

Example:
```
- [ ] CHP homepage (iPhone) — Daily Hope card requires scrolling to see
- [ ] hub footer (all) — too much empty vertical space below links
```
