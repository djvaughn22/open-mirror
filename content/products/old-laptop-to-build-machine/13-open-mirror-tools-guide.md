# Using Open Mirror's Tools to Decide What's Next

You now have a working development machine and one small live project.
This section is about what comes after — deciding what to actually build.
These are real, free, currently-live tools. None of them are required to
keep going; they're here if you want somewhere to start.

## Open Mirror — openmirrorllc.com

The home base. It's a plain, honest list of everything Open Mirror has
built — real, working products, not concepts. Browse it if you want a
sense of what's possible with the exact toolset you just installed, or
just want to see finished examples before starting your own idea.

## StepInTheRing — stepinthering.com

The most directly useful tool for what comes right after this bundle.
You answer a short series of questions about an idea, and it turns your
answers into a concrete first build plan — what to build first, in what
order. If you finish this bundle and think "okay, but what do I actually
build next," this is the place to bring that half-formed idea. It's free,
and the output is yours whether or not you go any further.

## Reflect — openmirrorllc.com/reflect

A quieter tool, less about planning and more about thinking something
through — a short set of open-ended prompts if you're stuck on what you
even want to make. Not required, but worth knowing it's there.

## What these tools don't do

None of them write your code for you, host your project, or replace the
walkthrough you just finished. StepInTheRing hands you a plan; you still
build it the way you built the Build Log in `09-first-project-walkthrough.md`
— write it, commit it, push it, deploy it.

## A realistic next step

A good second project is usually smaller than you think. Take one idea,
write down the smallest version of it that would actually work end to end,
and build that — the same loop you just used: `git init`, commit, push,
deploy. If you want help shaping that smallest version, that's exactly
what StepInTheRing is for.
