# Start Here

## What this is

You have an old laptop. It's slow, or it's just sitting in a drawer. This
guide turns it into a real Linux computer you can use to learn to code, build
small projects, and put real, working things on the internet — for free.

By the end you will have:

- A laptop running Linux, updated and secured
- The tools developers actually use: a code editor, Git, Python, Node.js
- A small real project, built by hand
- That project saved to GitHub
- That project **live on the internet**, at a real URL you can share

You do not need to already know Linux, the terminal, Git, or any of this.
Every term gets explained the first time it's used. Go slowly. Skipping steps
is the only way to get stuck.

## How this bundle is organized

Files are numbered in the order you'll use them. Start at `00-README.md` if
you haven't already — it explains what every file is for. Then work through
this list top to bottom:

1. **02-printable-checklist** — the whole journey on one page. Print it or
   keep it open on your phone.
2. **03-laptop-readiness-worksheet** — decide if your laptop can do this.
3. **04-backup-and-safety** — protect anything important before you touch
   the laptop.
4. **05-linux-installation** — put Linux on the machine.
5. **06-development-machine-setup** — install the tools you'll build with.
6. **07-terminal-command-reference** — keep this open in another tab.
7. **08-git-and-github-starter** — save your work, the way developers do.
8. **09-first-project-walkthrough** — build something real.
9. **10-deployment-walkthrough** — put it on the internet.
10. **11-troubleshooting** and **12-if-something-goes-wrong** — for when a
    step doesn't go as written.
11. **13-open-mirror-tools-guide** — what to do next, once the machine works.

## The promise, plainly

This is not a course, and it's not a shortcut to a job or a business. It's a
straight path from "I have an old laptop" to "I have a working computer with
a live project on it." What you build after that is up to you.

## Before you start

Read **04-backup-and-safety.md** before you do anything else, even if you're
excited to jump ahead. Installing Linux can erase everything currently on the
laptop. That section tells you exactly what to check first.
