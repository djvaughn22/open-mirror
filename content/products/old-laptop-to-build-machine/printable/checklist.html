Old Laptop to Build Machine

Printable checklist — check items off as you go.

Before you touch the laptop

  • Read 04-backup-and-safety.md
  • Filled out the laptop readiness worksheet
  • Anything important is backed up somewhere else
  • I know the Wi-Fi password, or have a wired connection
  • I have a USB flash drive, 8 GB or larger, I don't mind erasing
  • The laptop is plugged into power

Installing Linux

  • Downloaded a Linux install image
  • Created a bootable USB drive from that image
  • Booted the laptop from the USB drive
  • Installed Linux, erasing the drive on purpose (or set up dual-boot)
  • Laptop restarts into Linux on its own

First boot

  • Connected to Wi-Fi or ethernet
  • Ran a full system update
  • Set a strong login password
  • Confirmed automatic screen lock is on

Development tools

  • Installed Git
  • Installed a code editor
  • Installed Python
  • Installed Node.js and npm
  • Installed GitHub's command-line tool (gh)
  • Ran verify-setup.sh and everything shows installed

Git and GitHub

  • Created a free GitHub account
  • Set my name and email in Git
  • Signed in to GitHub from the terminal

First project

  • Created a project folder
  • Built the small project in the walkthrough
  • Ran it locally and saw it work in a browser
  • Turned the folder into a Git repository
  • Made my first commit
  • Created a matching repository on GitHub
  • Pushed my code to GitHub

Deployment

  • Turned on GitHub Pages for the repository
  • Visited the live URL and saw the project working
  • Made a small change, committed, pushed, watched it update live

After that

  • Read the Open Mirror tools guide
  • Decided what to build next
