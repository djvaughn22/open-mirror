# Laptop Readiness Worksheet

Answer these before you install anything. There's no wrong answer — this
just tells you what to expect.

## 1. How old is the laptop, roughly?

- [ ] Under 5 years — should run modern Linux comfortably
- [ ] 5–10 years — will likely run a lightweight Linux distribution well
- [ ] Over 10 years — still usable, but pick a lightweight option
      (see `05-linux-installation.md`) and keep expectations modest

## 2. How much RAM (memory) does it have?

If you don't know, that's fine — `05-linux-installation.md` shows how to
check from the current operating system, or you can look up the laptop's
model number online.

- [ ] 8 GB or more — comfortable for everyday development
- [ ] 4 GB — workable with a lightweight Linux distribution; avoid running
      many browser tabs and heavy programs at once
- [ ] 2 GB or less — usable for basic terminal-based work, but a modern code
      editor and browser together will feel slow

## 3. What kind of storage does it have — hard drive (HDD) or solid-state
   drive (SSD)?

An SSD is much faster. If it's an older spinning hard drive, Linux will
still run — it'll just feel slower opening programs. This doesn't stop you
from doing this project.

## 4. Does it power on and get through a normal boot reliably?

If the laptop won't turn on, won't charge, or the screen doesn't display
anything, that's a hardware problem this guide can't fix — that needs
repair or replacement first.

- [ ] Powers on and boots normally
- [ ] Has issues (note them here, and expect Linux to inherit the same
      hardware problem): _______________________

## 5. Does the keyboard, trackpad, and screen all work?

- [ ] Yes, all working
- [ ] Something doesn't work: _______________________ (you can still use an
      external keyboard/mouse/monitor if needed)

## 6. Is there anything currently on this laptop you need to keep?

If yes — stop here and go read `04-backup-and-safety.md` before continuing.
Installing Linux typically erases the existing operating system and
everything on it.

- [ ] Nothing important on this laptop — I'm ready to move on
- [ ] There is something important — I'm backing it up first

## Verdict

If the laptop powers on reliably and the basic hardware works, it's ready
for this project — Linux runs on a much wider range of hardware than most
people expect, including machines that struggle to run current Windows or
macOS versions. Move on to `04-backup-and-safety.md`.
