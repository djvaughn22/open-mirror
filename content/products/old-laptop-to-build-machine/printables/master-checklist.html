Old Laptop to Build Machine

Master Checklist

Tick each item as you go. Nothing needs to happen in one sitting.

Before you touch the laptop

  • Filled out the readiness worksheet
  • Backed up anything important, and confirmed it
  • Wrote down the Wi-Fi password
  • Have a USB stick, 8 GB+, to erase
  • Laptop plugged into power

Install Linux

  • Downloaded Linux Mint from the official site
  • Made a bootable USB stick (balenaEtcher)
  • Booted the laptop from the USB stick
  • Chose "erase and install" deliberately (or dual-boot)
  • Restarts into Linux Mint on its own

First boot

  • Connected to Wi-Fi or ethernet
  • Installed all updates, restarted
  • Set the screen to lock automatically
  • Opened a terminal

Development tools

  • Git installed
  • VS Code installed
  • Python installed
  • Node.js and npm installed
  • GitHub CLI (gh) installed
  • verify-setup.sh shows everything present

Git and GitHub

  • Created a free GitHub account
  • Set my name and email in Git
  • Signed in with gh auth login

First project

  • Made a project folder, opened it in VS Code
  • Built the Build Log
  • Ran it locally in a browser
  • Made a visible change
  • git init, first commit
  • Created the GitHub repo and pushed

Deployment

  • Turned on GitHub Pages
  • Visited the live URL — it works
  • Changed it, pushed, saw it update live

After that

  • Know where the code, folder, and URL are
  • Decided what to build next
