# Printable Checklist — Old Laptop to Build Machine

Print this page or keep it open on your phone while you work through the
guides. Check items off as you go. Nothing here needs to happen in one
sitting.

## Before you touch the laptop

- [ ] Read `04-backup-and-safety.md`
- [ ] Filled out `03-laptop-readiness-worksheet.md`
- [ ] Anything important on the laptop is backed up somewhere else (another
      computer, an external drive, or a cloud account)
- [ ] I know the laptop's Wi-Fi password, or have a wired internet
      connection
- [ ] I have a USB flash drive, 8 GB or larger, that I don't mind erasing
- [ ] The laptop is plugged into power (not just running on battery)

## Installing Linux

- [ ] Downloaded a Linux install image (see `05-linux-installation.md`)
- [ ] Created a bootable USB drive from that image
- [ ] Booted the laptop from the USB drive
- [ ] Installed Linux, and chose to erase the laptop's drive on purpose (or
      set up dual-boot, if that's what I decided)
- [ ] Laptop restarts into Linux on its own, without the USB drive

## First boot

- [ ] Connected to Wi-Fi or ethernet
- [ ] Ran a full system update
- [ ] Set a strong login password
- [ ] Confirmed automatic screen lock is on

## Development tools

- [ ] Installed Git
- [ ] Installed a code editor
- [ ] Installed Python
- [ ] Installed Node.js and npm
- [ ] Installed GitHub's command-line tool (`gh`)
- [ ] Ran `scripts/verify-setup.sh` and everything shows installed

## Git and GitHub

- [ ] Created a free GitHub account
- [ ] Set my name and email in Git (`git config`)
- [ ] Signed in to GitHub from the terminal (`gh auth login`)

## First project

- [ ] Created a project folder
- [ ] Built the small project in `09-first-project-walkthrough.md`
- [ ] Ran it locally and saw it work in a browser
- [ ] Turned the folder into a Git repository
- [ ] Made my first commit
- [ ] Created a matching repository on GitHub
- [ ] Pushed my code to GitHub

## Deployment

- [ ] Turned on GitHub Pages for the repository
- [ ] Visited the live URL and saw the project working
- [ ] Made a small change, committed it, pushed it, and watched the live
      site update

## After that

- [ ] Read `13-open-mirror-tools-guide.md`
- [ ] Decided what to build next
