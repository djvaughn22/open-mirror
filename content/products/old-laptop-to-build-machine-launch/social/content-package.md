# Social Content Package — Old Laptop to Build Machine

Internal draft for Instagram, YouTube Shorts, and longer YouTube. The content
**documents the real transformation** — an actual old laptop becoming a working
build machine — rather than just advertising a PDF. Direct, natural language.

**Rules baked in:** No promises of native Instagram or YouTube income. No
fabricated follower counts, view counts, or engagement. No "you'll get rich /
get a job" claims. Show the real process; let it be interesting on its own.

**Calls to action rotate among three** (never the same one twice in a row):
- **A) Free checklist** — "Grab the free readiness check (link in bio)."
- **B) Full playbook** — "The full step-by-step playbook is at Open Mirror
  (link in bio)." *(Only once it's actually available; until then use A or C.)*
- **C) Free exploration** — "Everything Open Mirror builds is at openmirrorllc.com
  — free to explore."

## Ten short-form video concepts (Reels / Shorts, 15–45s)

1. **The drawer laptop.** Pull a dusty old laptop out of a drawer, blow off the
   dust, open it. Text: "This has been dead for 3 years. Let's make it a coding
   machine." Hard cut to it running Linux. *CTA: A.*
2. **Boot race.** Split screen: the old laptop on its old OS (slow spinner) vs.
   after Linux (snappy). Text: "Same laptop. New life." *CTA: C.*
3. **The USB stick.** Close-up making the bootable USB in balenaEtcher. Text:
   "One $6 USB stick is all it takes to start." *CTA: A.*
4. **Back up FIRST.** A calm, serious 20 seconds: "Before you do ANY of this —
   back up. Installing Linux wipes the laptop. Here's the 2-minute version."
   *CTA: A.*
5. **First terminal command.** Screen-record typing `sudo apt update`, explain
   it in one breath. Text: "Your first real command. It's not scary." *CTA: C.*
6. **Installing the tools.** Time-lapse of the setup script running, tools
   ticking green on the verify script. Text: "Git, an editor, Python, Node —
   installed in one script." *CTA: B/C.*
7. **The first webpage appears.** Type a heading, save, refresh — it shows.
   Text: "I just built a website. On a laptop that was in the trash pile."
   *CTA: A.*
8. **git push → live.** Screen-record `git push`, then the live github.io URL
   opening on a phone. Text: "From my old laptop to the actual internet."
   *CTA: B/C.*
9. **Change it, watch it update.** Edit a color, push, refresh the live site.
   Text: "Edit → push → live. This is the whole loop." *CTA: C.*
10. **7-day recap.** Fast montage: dusty laptop → Linux → tools → website →
    live URL on a phone screen. Text: "7 days. One old laptop. One live site."
    *CTA: A.*

## Three longer YouTube video outlines

**Video 1 — "I turned a dead laptop into a coding machine (full walkthrough)"
(12–18 min).**
- Cold open: the finished live website on a phone, then "here's where it
  started" — the dusty laptop.
- The honesty up front: what this is, what it isn't, the backup warning.
- Readiness check (what makes a laptop a good candidate).
- Making the USB stick + installing Linux Mint (real screen capture, real snags
  shown, not edited to look effortless).
- First boot: updates, the terminal, the first command.
- Installing the dev tools with the setup script.
- Building the Build Log site; running it locally.
- Git → GitHub → GitHub Pages; the live URL reveal.
- "What I'd build next" + the free readiness check. *CTA: A, then C.*

**Video 2 — "Linux Mint for absolute beginners: the install, explained slowly"
(8–12 min).**
- Who this is for; the one supported path (Mint 22) and why.
- BIOS/UEFI and Secure Boot, in plain terms.
- The erase-vs-dual-boot choice and the data warning, carefully.
- First-boot updates and security basics.
- End on: "the machine's ready — here's what to put on it." *CTA: C.*

**Video 3 — "Your first website, from folder to live URL" (10–14 min).**
- Build the Build Log from an empty folder.
- Explain each file as it's created (no assumed knowledge).
- The Git loop, explained like it's the first time (because it is).
- Deploy on GitHub Pages; open the live link.
- Make one change and redeploy, to show the loop. *CTA: B/C.*

## Content sequences (post-by-post)

### Before-and-after sequence (3 posts)
1. **Before** — the dusty laptop, its slow old OS, "3 years in a drawer."
2. **During** — the install + tools montage, "same machine, mid-transformation."
3. **After** — the live website opening on a phone, "same laptop. now it ships
   websites." *CTA rotates A → C → A.*

### Required standalone posts
- **Laptop-readiness post.** Carousel/Short: the six-point check ("Can your old
  laptop do this?"). Ends on the free readiness check. *CTA: A.*
- **Backup-warning post.** Serious, useful, not fear-baity: "Installing Linux
  erases the laptop. Do this first." The 4-step backup. *CTA: A.*
- **First-terminal-command post.** Demystify `sudo apt update`: what each word
  means, why the password is hidden. *CTA: C.*
- **First-live-website post.** The github.io URL opening, "I made this today,
  from an old laptop." *CTA: B/C.*
- **Final-transformation post.** The full recap montage (see Concept 10 / Video
  1 cold open). Pin this one. *CTA: A.*

## Posting notes (internal)

- Keep screen recordings real — leave in a small stumble or a "wait, let me read
  that error." Beginners trust the honest version.
- Reuse the guide's design system for text overlays (deep blue + teal, clean
  sans) so the account looks like one coherent brand.
- Never overlay a fake view/like count or invent a testimonial.
- Alternate CTAs; don't hard-sell every post. Roughly 1 in 3 posts should be
  pure teaching with no product mention at all.
